# High Tide before 30 September 2026

Every file here carries the old High Tide, `#0A6CF0`.

It was replaced with `#0864E0` because the old value failed as text: 4.4:1 on
Sea Salt and 3.0:1 on Wet Slate, against the 4.5:1 WCAG floor for body text.
The new one is 5.4:1 on white and 5.0:1 on Sea Salt. The name did not change.

Nothing here is referenced by the site. It is kept so the exact previous
artwork can be recovered without going back through git.

- `styles.css` — the whole sheet, for the one token on line 8
- the three SVGs — source artwork
- the five PNGs — rasterised at the sizes the site ships
